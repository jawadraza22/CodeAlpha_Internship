# Vibe - Social Media App

A modern, attractive mini social media platform designed with glassmorphism, dynamic gradients, and smooth animations.

## Features
- **User Authentication**: Secure signup and login with JWT.
- **Profiles**: View user profiles, follow/unfollow users.
- **Posts**: Create posts with text and images, view your feed.
- **Interactions**: Like posts and comment on them.

## Tech Stack
- **Frontend**: HTML5, CSS3, Vanilla JavaScript, FontAwesome
- **Backend**: Node.js, Express.js
- **Database**: SQLite (via Sequelize)
- **Authentication**: JWT & bcrypt

## How to Run
1. Go to `backend` directory: `cd backend`
2. Install dependencies: `npm install`
3. Start backend server: `npm start`
4. Open `frontend/index.html` in a web browser. Note: some features work better when hosted through a Live Server due to CORS and absolute pathing, so using VS Code Live Server is recommended.
